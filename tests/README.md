# tests

Regression cases + baselines, MOCASSIN-suite style.  Each directory is
self-contained: grid (or its builder), input file(s), and a gate script
(`check_*.py`, or a `check_*.f90` that `run_check.sh` builds against the
compiled objects; `cloudy_c25` holds reference runs rather than a gate).
The gates of each stage are defined in md/PLAN.md section 5;
results are recorded in CLAUDE.md and docs/MoCHII_physics.pdf.

**Exit status.**  Every `check_*.py` and `run_check.sh` reports its verdict
through the exit status: 0 for PASS, nonzero for FAIL or for a missing input
file.  A script marked *diagnostic* below has no pass criterion (none is set
in it or here); it prints its numbers for reading and exits 0 whenever it
could read its inputs.  MoCHII itself ends a run it refuses on input
(namelist errors, values outside an item's set, MoCafe items it does not use)
with exit status 1.

**Before comparing two runs bit for bit**, note that bit identity needs the MPI
collective algorithm selection held fixed.  Confirmed here: with no code change
at all, two runs of the same binary on the same input at the same rank count
already differ — at 16 ranks on `cooling_ne/id_new.in` only 5 of the 31
`rates.h5` datasets matched bit for bit, with `J_nu` differing by 5.7e-14
(`_lines.txt` was identical).  Intel MPI choosing its collectives adaptively is
the diagnosis; pinning them with `I_MPI_ADJUST_ALLREDUCE=1` (plus `REDUCE`,
`BCAST`, `GATHER`) restores bit identity: confirmed 2026-09-25 at 8 ranks on
`cooling_ne/id_new.in`, where the pre-change binary and the
`hei_metastable_coupling = .false.` build agreed on all 31 `rates.h5` datasets
and on `_lines.txt` and `_nebcont.txt` byte for byte.  Without the pinning a
mismatch at the 1e-14 level is therefore not by itself a regression.

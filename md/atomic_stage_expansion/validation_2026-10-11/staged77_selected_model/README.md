# Prepared 77-stage chains with the selected production atom model

The exact staged element files were copied without regenerating their rates.
A directory link selects the installed `mocassin_v2` excitation model through
the actual production source selector. Actual species initialization, default
and enabled high-charge transfer, charge conservation, electron accounting,
mean kinetic heat, and population consumers passed 396 reaction-temperature
samples. Sixty-six enabled high-charge samples agree with the adopted
Langevin upper approximation. Source and executable hashes were verified.

This checks the new connection to the selected five-level S II product atom;
it does not substitute a 70-level model under an unrelated directory. The
controller is terminal completed. Production element files have not been
replaced: they still declare 43 metal stages and 32 adjacent transitions.
Ca VII excitation remains physically unresolved, so the global 77-stage
ionization/excitation/cooling objective is not complete. A full spatial
comparison and full thermal-balance solution have not been run.

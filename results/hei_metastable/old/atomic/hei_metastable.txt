# MoCHII He I 2^3S metastable (triplet) diagnostic coefficients.
# Closed-form rate fits + VFKY96 photoionization cross section for the
# 2^3S balance (Oklopcic & Hirata 2018, ApJ 855 L11 = OH18):
#   n_3 = [alpha_3 ne n_HeII + q_13 ne n_HeI]
#       / [A_31 + Phi_3 + ne (q_31a + q_31b + q_31g) + n_HI Q_31]
#   q_31g = q_13 (g_1/g_3) exp(E_13/kT), from the QEXC13 row (added in
#   hei_metastable_mod 2026-09-24; not in OH18)
# Transcribed from the EXHALE triplet implementation
#   (EXHALE/src/modules/radiation/Cool_coeff.f90, util_ion_eq.f90;
#    functions/cross_sec.f90::sigma_HeI23S).  Fortran evaluates the
#   closed forms; this file is the auditable coefficient source.
# generated by tools/fitting/make_hei_metastable.py
#
# Provenance:
#  alpha_3, alpha_1 : OH18 recombination into 2^3S / 1^1S systems.
#  q_13, q_31a, q_31b : Bray et al. (2000) collision strengths via
#     OH18 / Lampon et al. (2020); q_31a = 2^3S->2^1S, q_31b = 2^3S->2^1P
#     (spin-changing e-impact into the singlets, NOT 2^3S->1^1S).
#  A_31 = 1.272e-4 s^-1 (2^3S->1^1S, lifetime ~7870 s).  PITFALL: the
#     CHIANTI he_1.wgfa A(1-2)=1.73e-4 is ~36%% high; do NOT use it.
#  Q_31 : Penning + associative ionization He(2^3S)+H0, Garcia Munoz
#     (2025, A&A 698 A199) Fig. 5: Maxwellian average of the Movre &
#     Meyer (1997) cross sections, k = 1e-9 exp(c/T + d1 lnT + d2 lnT^2
#     + d3 lnT^3), <2%% over 200-1e4 K; reproduces the paper's Table A.5.
#     c is DIVIDED BY T (the paper's network file prints exp(c)).
#     Replaces Taylor et al. (2025) Table 2, a two-branch power law that
#     jumps 1.57x at 4000 K and is 1.2-1.8x above this over 3e3-1e4 K.
#  sigma_3(E) : He 2^3S photoionization, two VFKY96 wings + a log-linear
#     bridge; ~4%% fit to Norcross (1971) + TOPbase (EXHALE sigma_HeI23S);
#     threshold 4.78 eV.  Cross-checked vs p-winds (same Norcross data).
#  q_10833 : 2^3S->2^3P collisional excitation (Stage 2 emission source,
#     recorded only; Black 1981 form).
#  LINE10833 : 2^3S->2^3P_{0,1,2} fine-structure line constants for the
#     10833 A line-center absorption opacity (Stage 2).  Vacuum
#     wavelength [A], oscillator strength f, Einstein A [s^-1].  NIST
#     ASD (Drake 2007) values, via p-winds (p_winds/lines.py).  A-value
#     RESOLUTION: NIST/p-winds give A=1.0216e7 s^-1 for each component; the
#     CHIANTI he_1.wgfa ~1.15e7 (~13%% high) is NOT used.  All three
#     components share A (f split 1:3:5 by g_u cancels g_l/g_u in A_ul).
#     J'=1,2 (10833.217, 10833.306) blend (0.089 A << Doppler ~0.4 A at
#     1e4 K) = the observed 'doublet'; J'=0 (10832.057) is resolved.
#
